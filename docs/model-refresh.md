# Model refresh

Use the frozen set in `benchmarks/template-validation/` to review template defaults when Gemini models appear or disappear. Set `GEMINI_API_KEY` and `GCP_PROJECT_ID` in your local `.env` and configure BigQuery credentials for that project.

1. Run `npm run model:discover`. Review new and missing models, including missing IDs used by defaults. Add the probed entries to `src/agents/modelConfig.ts`, assign each a tier, and set its rates from [Gemini API pricing](https://ai.google.dev/gemini-api/docs/pricing). Keep model IDs pinned and exclude `*-latest` aliases.
2. Run `npm run tv:setup` for a new machine or project. It creates the `tv_thelook` views over `bigquery-public-data.thelook_ecommerce` and generates the template dbt artifacts. Run `npm run tv:label` only when building a new set version, with authenticated local agent CLIs. Labels require unanimous agreement. The default is three distinct families. Two produce a reduced quorum, and one requires `npm run tv:label -- --allow-single-family`. Multiple CLIs from the same family count once.
3. Run `npm run sweep:template`. It runs `node-sweep --corpus template` for all 12 nodes using the frozen set and writes `benchmarks/results/<date>-model-refresh.md` and `benchmarks/results/<date>-model-refresh.json` locally.
4. Review the reduced-quorum or single-family banner if present. Apply eligible strong or medium recommendations. Record the judgment behind any eligible weak recommendation in the commit message. A row is ineligible if ε > 0.05, the scores are flat at the floor, the recommendation equals the current profile, the model resolves to the same ID with the same thinking level, a local `MODEL_ID_OVERRIDES` affected the measurement, or infrastructure failures affected the comparison. The SQL cross-pass reverts the supervisor pick if the metric drops by more than ε or the loop-exhaustion rate rises by more than ε.
5. Update the applicable `DEFAULTS` entries in `src/agents/nodeProfiles.ts` and align the model defaults in `.env.example` and the `DEFAULT_*_MODEL` constants. Mark superseded registry entries `retired` once no default or documented override uses them.
6. Commit only the default changes and their supporting registry updates. Cite the set version and measurement date in each measured `DEFAULTS` comment, for example `TEMPLATE-MEASURED tv-v1 2026-12-02`. The refresh reports are gitignored. Keep benchmark evidence, project IDs, store IDs, and client data local.

Installations can run `npm run node-sweep` against their own corpus. Size install-coupled nodes on local data and set `NODE_PROFILE_OVERRIDES` according to the [per-node sizing rules](../src/agents/CLAUDE.md).
